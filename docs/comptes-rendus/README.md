# Comptes rendus de réunion

> **CP 4** — *« Les comptes rendus de réunion sont structurés, rédigés dans un style adapté, dans
> le respect des règles orthographiques et grammaticales, et contiennent les informations
> nécessaires ».*

Un fichier par point d'étape, nommé `AAAA-MM-JJ-objet.md`, à partir du [modèle](./MODELE.md).

## Ce qui compte comme réunion

Le projet est mené en autonomie, mais la compétence reste évaluée. Comptent comme réunions de
suivi, et doivent être consignées :

- les **points d'étape avec le formateur** — il tient le rôle du commanditaire ;
- les **revues de livrable** (validation des maquettes, du modèle de données, du dossier) ;
- les **points d'alerte**, quand un retard ou un arbitrage de périmètre est porté au formateur.
