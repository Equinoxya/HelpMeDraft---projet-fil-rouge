# ==============================================================================
# HelpMeDraft — dépendances Python du backend
# ------------------------------------------------------------------------------
# Installation :
#   cd backend
#   python -m venv .venv
#   .venv\Scripts\activate        (Windows)  |  source .venv/bin/activate  (macOS/Linux)
#   pip install -r requirements.txt
#
# Versions figées volontairement (reproductibilité des builds et de la CI).
#
# CE FICHIER EST LA SOURCE, PAS CE QUI EST INSTALLÉ EN CONTENEUR.
#
# Il ne verrouille que les dépendances DIRECTES. Les transitives — Werkzeug,
# Jinja2, itsdangerous... — restaient libres de changer d'une installation à
# l'autre (ticket KAN-102). Deux verrous en sont dérivés, avec les empreintes
# de chaque archive :
#
#     requirements.lock        production, utilisé par backend/Dockerfile
#     requirements-dev.lock    + outils de test et Ruff, utilisé par la CI
#
# Les régénérer après toute modification ici :
#
#     pip install pip-tools
#     pip-compile --generate-hashes --strip-extras \
#                 --output-file=requirements.lock requirements.txt
#
# Les empreintes ne sont pas du zèle : installées avec --require-hashes, elles
# font échouer l'installation si un paquet a été altéré sur l'index.
# ==============================================================================
